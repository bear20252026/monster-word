## 三、问题归因分析

### 3.1 text3（三级文字）— α=97 太浅（6 项，全主题）

**根因**：`text3` 使用 38% 不透明度（`#61000000` / `#61FFFFFF`），alpha=97 在任何背景上合成后对比度均不足。

| 主题 | 合成等效色 | 背景 | 实测 |
|---|---|---|---|
| 明亮 | `#989898` | `#F5F5F5` | 2.65:1 |
| 明亮 | `#9E9E9E` | `#FFFFFF` | 2.68:1 |
| 深邃 | `#9B9F9E` | `#212532` | 3.46:1 |
| 深邃 | `#A0ACA9` | `#2E344A` | 3.18:1 |
| 极夜 | `#636363` | `#040404` | 3.41:1 |
| 极夜 | `#717272` | `#1A1B1C` | 3.57:1 |

**修复建议**：
- 方案 A（推荐）：提高 alpha 至 ≥ 0.62（参考 `a11y_dark_mode_report.md` α 阶梯，α=0.62 在三层表面全部 ≥ 4.5）
- 方案 B：使用固定 hex 色值替代半透明（如明亮 `#757575`、深邃/极夜 `#9B9F9E`）

### 3.2 accent（强调色）— 不应用作文字色（6 项）

**根因**：accent 色值（`#E8913A` 橙、`#005F87` 蓝）是为按钮填充/图标设计的，对比度仅 2.25–2.92:1，不满足文字 4.5:1 要求。

| 主题 | accent 色 | on 浅底 | on 深底 |
|---|---|---|---|
| 明亮 | `#E8913A` | 2.25:1 | 2.46:1 |
| 极夜 | `#005F87` | 2.92:1 | 2.45:1 |

**修复建议**：
- 区分"强调色填充"和"强调色文字"两套 token
- 明亮主题强调文字用 `#CC7A2E`（primaryDeep，约 4.8:1 on 白）
- 极夜主题强调文字用 `#4A90E2`（更亮的蓝，约 5.2:1 on 纯黑）
- 或将 accent 文字场景的阈值降为 3.0（仅限大号元素 ≥18pt）

### 3.3 success / danger / teal — 语义色对比度不足（7 项）

**根因**：Material 默认语义色（`#4CAF50`、`#E3303B`、`#4A90E2`）在浅色背景上对比度普遍偏低（2.5–4.0:1），暗色变体（`#22A18B`、`#C64354`）在深色反馈底上也不足。

**修复建议**：

| Token | 当前值 | 问题场景 | 建议替代值 | 预估对比度 |
|---|---|---|---|---|
| `success`（明亮） | `#4CAF50` | on `#F5F5F5` = 2.55 | `#2E7D32` | ~6.5 |
| `danger`（明亮） | `#E3303B` | on `#F5F5F5` = 4.05 | `#C62828` | ~5.9 |
| `teal`（明亮） | `#4A90E2` | on `#F5F5F5` = 3.02 | `#1565C0` | ~5.8 |
| `danger`（深邃） | `#C64354` | on `#212532` = 3.15 | `#EF5350` | ~5.6 |
| `quizCorrectText`（明亮） | `#4CAF50` | on `#D1FAE5` = 2.45 | `#1B5E20` | ~5.8 |
| `quizCorrectText`（深邃） | `#22A18B` | on `#1A3D2E` = 3.73 | `#4DB6AC` | ~5.4 |
| `quizWrongText`（全主题） | 变体 | 在反馈底上 | 白色文字 | ~5.0+ |

### 3.4 quiz 反馈色 — 文字/背景明度差不够（5 项）

**根因**：正确反馈（绿字 on 浅绿底）和错误反馈（红字 on 浅红底）的前景/背景明度差太小。

**修复建议**：
- 明亮主题：quiz 文字色改用深色变体（答对 `#1B5E20`、答错 `#B71C1C`）
- 暗色主题：quiz 背景色加深或文字色提亮（答对文字 `#4DB6AC`、答错文字 `#EF5350`）

| 优先级 | 问题 | 影响配对数 | 修复方案 |
|---|---|---|---|
| **P0** | text3 α 太浅 | 6 | α ≥ 0.62 或换固定色值 |

| **P1** | accent 用作文字 | 6 | 区分填充/文字两套 token |
| **P1** | success/teal 在浅底 | 4 | 浅底用深色变体 |
| **P2** | danger 在浅底 | 2 | 同上，差距较小 |

## 六、建议的 Token 调整方案

以下为最小改动方案，仅调整不达标场景的色值：

```dart
// skin_system.dart 中需要修改的值

// 明亮主题
text3: Color(0x99000000),           // α=153 (60%)，替代 α=97 (38%)
success: Color(0xFF2E7D32),         // 深绿，替代 #4CAF50
danger: Color(0xFFC62828),          // 深红，替代 #E3303B
teal: Color(0xFF1565C0),           // 深蓝，替代 #4A90E2
quizCorrectText: Color(0xFF1B5E20), // 深绿文字
quizWrongText: Color(0xFFB71C1C),   // 深红文字

// 深邃主题
text3: Color(0x99FFFFFF),           // α=153 (60%)
danger: Color(0xFFEF5350),          // 提亮红
quizCorrectText: Color(0xFF4DB6AC), // 提亮青绿
quizWrongText: Color(0xFFEF5350),   // 提亮红

// 极夜主题
text3: Color(0x99FFFFFF),           // α=153 (60%)
accent: Color(0xFF4A90E2),          // 提亮蓝（或新建 accentText token）
teal: Color(0xFF4A90E2),            // 同上
quizCorrectText: Color(0xFF4DB6AC), // 提亮青绿
quizWrongText: Color(0xFFEF5350),   // 提亮红
```

> **注意**：以上建议值为估算，实施时需用 WebAIM Contrast Checker 验证精确对比度。accent 的修改需评估视觉影响——如仅用于大号元素可降阈值至 3.0 而不改色值。
