## 一、计算方法

**相对亮度（Relative Luminance）**，按 WCAG 定义：

```
对每个通道 sRGB 值 c ∈ [0,1]：
  c_lin = c / 12.92                      （c ≤ 0.03928）
  c_lin = ((c + 0.055) / 1.055) ^ 2.4    （c > 0.03928）

L = 0.2126 × R_lin + 0.7152 × G_lin + 0.0722 × B_lin
```

**对比度比值**：

```
ratio = (L_亮 + 0.05) / (L_暗 + 0.05)，结果范围 [1, 21]
```

**半透明文字的处理**：`rgba(0,0,0,x)` 这类带 alpha 的前景色先与底色做 alpha 合成得到等效实色再计算：

```
result = α × foreground + (1 − α) × background   （逐通道，0–255）
```

**判定标准**：

| 级别 | 正常文字 | 大号文字 |
|---|---|---|
| AA | ≥ 4.5 : 1 | ≥ 3 : 1 |
| AAA | ≥ 7 : 1 | ≥ 4.5 : 1 |

> "大号文字"定义：≥ 24px（18pt）常规字重，或 ≥ 18.66px（14pt）粗体。
> 本项目 CTA 按钮标签为 14–16px / weight 600、Rewards 星标 pill 为 13px / weight 700，均**不构成大号文字**，一律按正常文字 4.5:1 判定。

**工具方法**：以上公式用 PowerShell 脚本逐项精确计算（保留 4 位小数的亮度、2 位小数的比值）；可用 WebAIM Contrast Checker（webaim.org/resources/contrastchecker）或浏览器 DevTools 的对比度提示交叉复核。

**关键表面亮度值**：

| 表面 | 色值 | 相对亮度 L |
|---|---|---|
| White 卡片 | `#ffffff` | 1.0000 |
| Neutral Warm 奶油画布 | `#f2f0eb` | 0.8720 |
| Ceramic 陶瓷画布 | `#edebe9` | 0.8330 |
| Green Accent | `#00754A` | 0.1322 |
| Starbucks Green | `#006241` | 0.0912 |
| House Green | `#1E3932` | 0.0343 |
| Gold | `#cba258` | 0.3924 |
| Text Black `#212121` | — | 0.0152 |

## 三、逐项详细分析

### 1. 正文 Text Black rgba(0,0,0,0.87) ≈ `#212121` on 奶油画布

- `rgba(0,0,0,0.87)` 在纯白上合成 = 0.13×255 ≈ 33 → `#212121`；在奶油画布上真实合成值为 `#1F1F1F`，差异可忽略（后者对比度 14.47:1 / 13.87:1）。
- **on `#f2f0eb`：14.14 : 1**（L=0.0152 vs 0.8720）→ AAA 通过
- **on `#edebe9`：13.54 : 1** → AAA 通过

✅ **结论：完全达标，直接使用。** 富余量极大（超 AAA 标准约一倍），是整个系统的安全基线。

### 2. 次要文字 rgba(0,0,0,0.58) on 两块画布 —— ⚠️ 与预期不符：实际**通过 AA**

合成结果与比值（脚本实测）：

| 底色 | 合成等效色 | 对比度 | AA 正常(4.5) | AAA(7.0) |
|---|---|---|---|---|
| `#f2f0eb` | `#666563` | **5.11 : 1** | ✅ 通过 | ❌ |
| `#edebe9` | `#646362` | **5.04 : 1** | ✅ 通过 | ❌ |

任务前假设"大概率不达标"，实测**并非如此**：α=0.58 的黑在暖奶油底上的等效色比预想的深，对比度约 5.0–5.1，**满足 AA 正常文字要求**，且有约 13% 余量。

**风险提示与建议**：
1. **可以放心继续用 α=0.58 做 metadata/说明文字（AA 场景）。**
2. 若目标含 AAA，或希望给深色模式/低端屏幕留余量，建议加深至 **α=0.68–0.70**（实测 7.44 / 8.01:1，AAA 通过）。加深到 0.62 仅得 5.96:1，仍不过 AAA，意义不大——要加就加到 0.68+。
3. **红线**：α 不要降到 0.55 以下。实测 α=0.52 时仅 4.16:1（AA 失败），α=0.55 时 4.61/4.54:1（勉强贴线）。

Alpha 阶梯实测（cream / ceramic）：

| α | 0.52 | 0.55 | 0.58 | 0.60 | 0.62 | 0.65 | 0.68 | 0.70 | 0.72 |
|---|---|---|---|---|---|---|---|---|---|
| 对比度 | 4.16 / 4.10 | 4.61 / 4.54 | **5.11 / 5.04** | 5.52 / 5.44 | 5.96 / 5.87 | 6.64 / 6.55 | 7.44 / 7.31 | 8.01 / 7.82 | 8.67 / 8.46 |
| AA | ✗ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| AAA | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |

### 3. 白字 on Green Accent `#00754A`（主 CTA）

- 对比度：**5.76 : 1**（L=1.0000 vs 0.1322）
- AA 正常文字（按钮标签 14–16px/600 属正常文字）：✅ 通过，余量约 28%
- AAA：❌（需 7.0）

✅ **结论：AA 达标，主 CTA 可直接使用。**
可选增强：若个别界面需要 AAA（如无障碍重点页面），可将该按钮填充色换成 Starbucks Green `#006241`，白字对比度升至 **7.44 : 1**（AAA 通过）；但常规场景不必——保持 Green Accent 作为 CTA 专属色的角色分工更重要。

### 4. 白字 on House Green `#1E3932`（深绿横幅）

- 对比度：**12.45 : 1**（L=1.0000 vs 0.0343）
- AA / AAA 全部通过。

✅ **结论：完全达标，直接使用。** 特性横幅、footer、产品描述带的白字都非常安全。（补充参考：DESIGN.md 中的次要暗底文字 `rgba(255,255,255,0.70)` 是另一组合，不在本次任务清单内，如需可另行验证。）

### 5. 绿字 `#00754A` on 白卡片（描边按钮文字）

- 对比度：**5.76 : 1**（与第 3 项互为反色，数值相同）
- AA 正常文字：✅ 通过；AAA：❌

✅ **结论：AA 达标，描边按钮（"Give them a try"、"Customize"）可直接使用。**
可选增强：描边按钮文字若要 AAA，可改用 `#006241`（7.44:1），边框仍可用 `#00754A` 保持视觉亮度；非必需。

### 6. 金色 `#cba258` 字 on 深绿 `#1E3932` —— ⚠️ 实测好于预期：通过 AA

- 对比度：**5.25 : 1**（L=0.3924 vs 0.0343）
- AA 正常文字：✅ 通过（典型用法 Rewards Cost Pill「200★ item」为 13px/700，属正常文字）
- AAA：❌（需 7.0）

✅ **结论：AA 达标，金色文字在深绿底上可以直接使用**（此前担心的 3:1~4:2 区间问题不存在）。
可选增强：若要 AAA，改用系统内已有的 **Gold Light `#dfc49d`** 作深底金字，实测 **7.42 : 1**（AAA 通过），且本来就是 DESIGN.md 定义的 token，不引入新色值。金色描边（pill 边框属非文字 UI）只需 3:1，5.25:1 绰绰有余。

### 7. Starbucks Green `#006241` 标题字 on 奶油画布

| 底色 | 对比度 | AA 正常 | AAA 大字(4.5) | AAA 正常(7.0) |
|---|---|---|---|---|
| `#f2f0eb` | **6.53 : 1** | ✅ | ✅ | ❌ |
| `#edebe9` | **6.26 : 1** | ✅ | ✅ | ❌ |

✅ **结论：AA 达标，可直接使用。** H1 为 24px/600，按 WCAG 属"大号文字"，其 AAA 适用标准为 ≥4.5:1，**已满足**——即标题绿实际上达到 AAA（大字）级。仅在把绿色用于**小号正文**（<18.66px 粗体）时才需要注意它不到 7:1。
可选增强：若有小字绿色文本需求，可引入更深的 `#005243`（on cream 实测 8.06:1，AAA 全通过），但作为标题用途无需改动品牌色。

## 四、总结

### ✅ 可直接使用的组合（7 项中 7 项 AA 全部达标）

| 组合 | 对比度 | 上限级别 |
|---|---|---|
| 正文黑 on 两块画布 | 13.5–14.1 : 1 | AAA |
| 次要文字 α=0.58 on 两块画布 | 5.0–5.1 : 1 | AA |
| 白字 on Green Accent CTA | 5.76 : 1 | AA |
| 白字 on House Green 横幅 | 12.45 : 1 | AAA |
| 绿字 on 白卡片描边按钮 | 5.76 : 1 | AA |
| 金字 on House Green | 5.25 : 1 | AA |
| 标题绿 on 两块画布 | 6.26–6.53 : 1 | AA（大字 AAA） |

**核心结论：星巴克这套配色在本项目的全部 7 组关键文字/背景组合均满足 WCAG AA，无一需要强制修改。**

### 🔧 可选优化（均为锦上添花，非必需）

1. 次要文字若要冲 AAA 或留更多余量：α 从 0.58 提到 **0.68–0.70**（一步到位，0.62 无实质收益）；
2. 金色文字若要 AAA：深底金字改用现成 token **Gold Light `#dfc49d`**（7.42:1）;
3. 个别需要 AAA 的绿色小字：换 `#006241`（白底 7.44:1）或更深 `#005243`。

### ⚠️ 使用红线（避免未来回归）

- 次要文字 alpha **不得低于 0.55**（0.52 即 AA 失败）；
- Green Accent `#00754A` 不要用作奶油画布上的**小号文字**颜色（on cream 约 5.4:1，AA 尚可但接近场景边缘；更重要的是它与画布的组合弱于白底）；
- 标题绿 `#006241` 不要用于 <18.66px 的非粗体小字（AAA 视角不足 7:1）。
