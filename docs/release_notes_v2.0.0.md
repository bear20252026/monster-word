# Monster Word v2.0.0 发布说明

> 发布日期：2026-08-24
> 版本号：2.0.0+2
> 适用平台：Windows / Android

---

## 🎨 版本亮点：全新星巴克设计语言

Monster Word 迎来 v2.0 重大视觉升级！整个 App 采用星巴克设计语言进行了全面重构，带来温暖、精致、一致的学习体验。

**核心变化一览：**
- 🟢 奶油色画布（#F2F0EB）替代纯白背景，更护眼、更有质感
- 🟢 品牌绿色系四层配色（#006241 / #00754A / #1E3932 / #2B5148），统一视觉语言
- 🟢 全新双主题：「星巴克奶油」（亮色）+「星巴克深绿」（暗色），昼夜皆宜
- 🟢 全新启动屏：奶油色/深绿色品牌背景，视觉焕新
- 🟢 应用名统一为「Monster Word」，告别默认占位名

---

## ✨ 新功能与改进

### 设计系统

- **全新 Token 层**：30 个语义颜色令牌，亮/暗双主题完整定义
- **10 个星巴克组件**：
  - `SbButton` — 胶囊按钮（4 种变体：主色/描边/黑色/反白）
  - `SbCard` — 双层低透明度阴影卡片（12px 圆角）
  - `SbFab` — 56px Frap 悬浮按钮
  - `SbBanner` — 深绿特性横幅
  - `SbBadge` — 金色胶囊徽章
  - `SbDropdown` — 下拉菜单
  - `SbModal` — 模态对话框
  - `SbProgress` — 绿色进度指示器
  - `SbSegmented` — 分段控件
  - `ScaleDownOnPress` — 统一按压反馈（scale 0.95）
- **字体系统**：Inter 字体 + 中西文混排回退链（PingFang SC / Microsoft YaHei / Noto Sans SC）
- **动效规范**：五档时长（150ms/200ms/300ms）+ 克制缓动曲线

### 页面改造

- **首页**：奶油色画布 + 内容卡片重构
- **学习页**：答题动效完整链——选错抖动收敛 + 选对绿色确认 + 防重复点击
- **词书选择页**：星巴克风格书封 + 奶油画布
- **单词详情页**：星巴克配色应用
- **个人资料页**：移除渐变，奶油画布
- **外观设置页**：全新主题选择器 UI
- **搜索页**：星巴克风格搜索界面
- **设置页**：星巴克风格改造

### 系统改进

- **主题持久化**：切皮肤 → 杀进程 → 重启仍保持选择
- **跟随系统**：真正的系统深浅色跟随开关（双通道监听）
- **亮度语义拆分**：UI 亮度与状态栏亮度独立控制
- **启动屏**：Android 浅色（奶油 #F2F0EB）/ 深色（深绿 #1E3932）双模式
- **Android 12+ 适配**：SplashScreen API 支持
- **应用名统一**：全平台一致显示「Monster Word」

### 无障碍

- **WCAG 对比度守卫**：自动化测试覆盖亮/暗双主题所有语义颜色对
- **触控目标审计**：最小 48dp 命中区域合规排查
- **暗色模式对比度验证**：深绿三层体系全部 AA 达标

### 数据修复

- **音标清洗**：修复 129 处误录字符（68 冒号 → 长音符 ː，61 撇号 → 主重音符 ˈ）
- **字体修复**：解决未注册 phonetic 字体家族导致的音标回退问题
- **编译修复**：清除 4 个阻塞编译的 ERROR

---

## 🔧 已知限制

- **对比度守卫部分未达标**：旧主题（明亮/深邃/极夜）的少量颜色对未达 WCAG 4.5:1 阈值，属于设计 token 调优范畴，不影响核心功能
- **词典数据合规待处理**：内置词典数据（wordbook.db）存在版权风险，计划用开源 ECDICT 替换（详见 docs/dictionary_license_review.md）
- **启动屏 logo 待补**：当前为纯色背景，品牌 M 图标素材就绪后追加
- **Windows 构建**：需安装 Visual Studio C++ 工具链才能编译
- **部分死页面未改造**：约 25 个未接入主路径的页面保持原样，仅 13 个活跃页面完成改造
- **柯林斯词典 Tab**：UI 已建但数据层为空，显示「暂无柯林斯释义数据」

## 📋 升级说明

- **版本号**：1.0.0+1 → 2.0.0+2（大版本升级）
- **Windows exe**：从 `word_app.exe` 改为 `MonsterWord.exe`，旧桌面快捷方式需重新创建
- **数据兼容**：用户词书数据和学习进度完全兼容，无需迁移
- **主题重置**：首次启动如遇主题异常，请在「外观设置」中重新选择
