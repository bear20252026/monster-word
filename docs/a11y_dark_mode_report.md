# 暗色主题对比度预审：深绿三层体系验证报告

> 项目：Monster Word（D:\claude\work\cn_com_lange\word_app）
> 对象：ThemeAnalyst 起草中的暗色主题——画布 `#101B17` 墨绿近黑 / 表面卡片 `#1E3932` / 提亮层 `#274A40` / 强调 `#00A862` 薄荷绿
> 参照：docs/dark_skin_strategy.md L143–152 的 token 草稿（只读对照，未修改）；本组前序报告 docs/a11y_contrast_report.md（亮色版，7 组全部 AA 达标）
> 依据：WCAG 2.1 SC 1.4.3（AA：正常文字 ≥4.5:1，大字 ≥3:1）、SC 1.4.6（AAA：7:1 / 4.5:1）
> 审计日期：2026-08-24　|　约束：只新建本文件

## 一、计算方法与表面基准

计算方法与亮色版完全一致（WCAG 相对亮度公式 + alpha 合成 + `(L亮+0.05)/(L暗+0.05)`），脚本精确计算，可用 WebAIM 复核。

三层表面亮度（暗色层级从深到浅，对比度判定以"最亮的表面"为最严苛场景）：

| 层级 | 色值 | 相对亮度 L | 用途 |
|---|---|---|---|
| Canvas 画布 | `#101B17` | 0.0096 | 页面基底 |
| Surface 卡片 | `#1E3932` | 0.0343 | 卡片/浮层（与 House Green 同源） |
| Surface High 二级浮层 | `#274A40` | 0.0570 | 弹窗、菜单 |
| Accent 强调 | `#00A862` | 0.2889 | 薄荷绿强调色 |

## 二、任务指定组合实测结果

### 1. 正文 rgba(255,255,255,0.87) 与次要文字 rgba(255,255,255,0.58)

| 前景（合成等效色） | 底 | 对比度 | AA 正常 | AAA | 判定 |
|---|---|---|---|---|---|
| 正文白 0.87（≈`#e0e1e1`） | 画布 `#101B17` | **13.45 : 1** | ✅ | ✅ | 直接采用 |
| 正文白 0.87（≈`#e2e5e4`） | 表面 `#1E3932` | **9.82 : 1** | ✅ | ✅ | 直接采用 |
| 正文白 0.87（≈`#e3e7e6`） | 浮层 `#274A40` | **7.87 : 1** | ✅ | ✅ | 直接采用 |
| 次要白 0.58（≈`#9b9f9e`） | 画布 `#101B17` | **6.59 : 1** | ✅ | ❌ | AA 采用 |
| 次要白 0.58（≈`#a0aca9`） | 表面 `#1E3932` | **5.32 : 1** | ✅ | ❌ | AA 采用 |
| 次要白 0.58（≈`#a4b3af`） | 浮层 `#274A40` | **4.51 : 1** | ⚠️ 贴线 | ❌ | 见红线建议 |

要点：暗色的"白字叠加"机制比亮色"黑字叠加"更有利——同一 α=0.58，暗色画布上得 6.59（亮色仅 5.04–5.11），因为底色更深。但**在提亮层 `#274A40` 上已贴到 4.51 的及格线**，弹窗/菜单里的次要文字没有任何余量。

### 2. 白字 / 薄荷绿字 on `#1E3932` 卡片

| 组合 | 对比度 | 判定 |
|---|---|---|
| 白字 on `#1E3932` | **12.45 : 1** | AAA ✅ 卡片正文字首选 |
| 薄荷绿 `#00A862` 字 on `#1E3932` | **4.02 : 1** | ❌ AA 正常文字**不达标**（仅过大字 3:1 与非文字图形 3:1） |
| （参照）薄荷绿 on 画布 | 5.69 : 1 | AA ✅ AAA ❌ 可用于画布上的小字强调 |
| （参照）薄荷绿 on `#274A40` | 3.17 : 1 | ❌ 仅大字/图形 |

**结论：`#00A862` 不能作为卡片上的小号强调文字。** 它在暗色体系里的正确角色是图标、描边、大标题（≥18.66px 粗体）和图形强调；若确需卡片上的绿色小字（如链接、标签），请换用提亮档 **`#00C77F`**：on 表面 5.62:1 ✅、on 画布 7.96:1 AAA ✅。

### 3. 薄荷绿 `#00A862` 作强调色文字 on 画布 `#101B17`

- 对比度 **5.69 : 1** —— AA 通过，AAA 未过。
- 与亮色版语义对位良好：亮色主绿 `#00754A` on 奶油画布为 5.06:1、标题绿 `#006241` 为 6.53:1，暗色薄荷绿 5.69 恰落在两者之间，昼夜强度衔接自然。✅ 可直接作为暗色强调文字色（限画布场景）。

### 4. 金色系 on 深绿表面（成就徽章）

| 组合 | 对比度 | 判定 |
|---|---|---|
| 金 `#cba258` on `#1E3932` | **5.25 : 1** | AA ✅（与亮色版完全同值——两版共用同一对色，天然一致） |
| 浅金 `#dfc49d` on `#1E3932` | **7.42 : 1** | AAA ✅ 徽章数字/星标首选 |
| 金 `#cba258` on `#274A40` | 4.14 : 1 | ❌ 弹窗内金色小字不达标，改用浅金（5.85 ✅） |
| 浅金 `#dfc49d` on 画布 | 10.51 : 1 | AAA ✅ |

**结论：徽章体系直接沿用亮色版的金/浅金双 token 即可，规则同亮色——普通金字过 AA，重要数字用浅金过 AAA；唯一注意点是在 `#274A40` 弹层里一律用浅金。**

### 5. 反白 CTA（白底深绿字）的视觉层级是否成立

成立，且是暗色体系的正确选择：

- 视觉冲击力：纯白药丸 on `#101B17` 画布 = **17.63 : 1**，是全暗色界面中对比最高的元素，主 CTA 层级毫无歧义；
- 文字可读性：`#1E3932` 深绿字 on 白底 = **12.45 : 1**（AAA）；若用 Starbucks Green `#006241` 则为 7.44:1（AAA），两案皆可；
- **反面警示：不要用薄荷绿做实心按钮填充+白字**——白 on `#00A862` 仅 **3.10 : 1**，AA 正常文字直接失败。若必须做绿色实心按钮，填充用 `#00A862` 时文字应为深色：画布墨绿字 on 薄荷 = 5.69 ✅、黑字 = 6.78 ✅。
- 推荐方案：**主 CTA = 白底 + `#1E3932` 文字（或 `#006241`）**；次级按钮 = 透明底 + 薄荷描边 + 薄荷字（画布场景达标）。这与星巴克规范"反白药丸"的做法一致。

## 三、与 dark_skin_strategy.md token 草稿的对照验证

草稿 L152 自检数字 vs 实测：

| Token | 草稿声明 | 实测 | 结论 |
|---|---|---|---|
| `textPrimary #E8E3DA` on `#101B17` | ≈12.8:1 | **13.79:1** AAA | ✅ 成立（实际更好）；on 表面 9.74、on 浮层 7.68 全 AAA |
| `textSecondary #9DB0A9` on `#101B17` | ≈6.9:1 | **7.74:1** AAA | ✅ 画布上成立且达 AAA |
| `textSecondary #9DB0A9` on `#1E3932` | —（未声明） | **5.46:1** AA | ✅ 卡片上可用 |
| `textSecondary #9DB0A9` on `#274A40` | —（未声明） | **4.31:1** | ❌ **弹窗/菜单内不达标**（差 0.19） |
| `accentOnSurface #D4E9E2`（薄荷上的文字） | —（未声明对比度） | on `#00A862` = **2.44:1** | ❌❌ **全场景失败**（连大字 3:1 都不过） |

**两个必须修正的点：**

1. **`accentOnSurface #D4E9E2` 是整个暗色方案最大的坑**：浅薄荷字放在薄荷绿填充上只有 2.44:1，凡是薄荷实心元素上的文字/图标全部不可读。替换方案（按推荐序）：
   - 改用深色文字：`#101B17` on `#00A862` = **5.69:1** ✅（推荐，与画布同 token，零新增色值）；
   - 或纯黑 `#000000` on `#00A862` = 6.78:1（接近 AAA）；
   - 注意 `#006241` on 薄荷 = 2.40:1 也失败，"深绿字配薄荷底"这条路走不通，必须是近黑/墨绿档。
2. **`textSecondary` 在 `#274A40` 浮层上不达标**：二选一——
   - 提亮 token：`#9DB0A9` → **`#A9BCB5`**（on 浮层 4.93 ✅、on 表面 6.25 ✅、on 画布 8.36 左右仍 AAA 级），全局统一一个次级色；
   - 或约定 `#274A40` 只承载正文/标题不放次要文字（限制较多，不推荐）。

其余 token（`pageBg/surfaceRaised/surfaceHigh/accent/textPrimary`）全部通过预审。

## 四、昼夜语义一致性检查

| 语义层级 | 亮色实测 | 暗色实测 | 差值评估 |
|---|---|---|---|
| 正文 | 14.14（cream） | 13.45–13.79（画布） | ≈持平，夜间不刺眼 ✅ |
| 次要文字 | 5.04–5.11 | 画布 6.59–7.74 / 卡片 5.32–5.46 / 浮层 4.31–4.51 | 画布上略高于白天（合理，暗适应眼更需要确认度）；**浮层偏低且不达标**，修复后三档 4.93–7.74，节奏与亮色一致 ✅ |
| 强调文字 | 主绿 on 奶油 5.06 / 标题绿 6.53 | 薄荷 on 画布 5.69 | 落在亮色双值之间，衔接自然 ✅ |
| 主 CTA | 白字 on 绿 5.76 | 反白：深绿字 on 白 12.45（面冲击 17.63） | 夜间 CTA 更醒目——正确的方向（夜间操作目标应更突出）✅ |
| 金色徽章 | 5.25 / 7.42 | 同值（共用色对） | 完全一致 ✅ |
| 危险/错误红 | （未在本次范围） | 建议定稿时补测 on 三层表面 | ⚠️ 待补项 |

结论：三层体系本身没有"夜间过刺眼"风险（正文 13.x vs 亮色 14.x，几乎无感切换）；需要收敛的只有浮层次要文字一档。

## 五、α 阶梯与透明度红线（暗色次要文字）

白字 α 在三层表面上的实测（AA=4.5 行 / AAA=7 行）：

| α | 画布 `#101B17` | 表面 `#1E3932` | 浮层 `#274A40` |
|---|---|---|---|
| 0.46 | 4.63 ✅ | 3.94 ❌ | 3.44 ❌ |
| 0.50 | 5.23 ✅ | 4.36 ❌ | 3.77 ❌ |
| 0.52 | 5.57 ✅ | 4.60 ✅ | 3.95 ❌ |
| 0.55 | 6.03 ✅ | 4.96 ✅ | 4.24 ❌ |
| 0.58 | 6.59 ✅ | 5.32 ✅ | **4.51 ⚠️贴线** |
| 0.62 | 7.34 ✅AAA | 5.85 ✅ | 4.90 ✅ |
| 0.65 | 7.95 AAA | 6.26 ✅ | 5.23 ✅ |
| 0.70 | 9.09 AAA | 7.00 AAA | 5.78 ✅ |

**红线与建议：**

1. **硬红线：α < 0.55 禁止用于任何表面的次要文字**（0.52 时浮层已跌至 3.95）；
2. **工程安全线：统一 α ≥ 0.62**——这是让三层表面全部 ≥4.5 的最低整档值（7.34 / 5.85 / 4.90），且画布场景顺带拿到 AAA；
3. 若想一套 α 通吃并留余量：**α = 0.65**（7.95 / 6.26 / 5.23）；
4. 若采用草稿式固定 hex token（当前草案即如此）：等价规则为「次要文字色在三档表面上分别 ≥4.93/5.46/7.74」，即直接采纳上文 `#A9BCB5` 替换 `#9DB0A9`；
5. AAA 目标下限提示：浮层层即使 α=0.72 也只有 5.99，**浮层上的次要文字永远拿不到 AAA(7:1)**——如需 AAA 场景，浮层里只放正文/标题档颜色。

## 六、结论清单

### ✅ 可直接采用

| 项 | 数值 |
|---|---|
| 三层表面体系本身（画布/表面/提亮） | `#101B17` / `#1E3932` / `#274A40`，亮度梯度健康（0.010→0.034→0.057） |
| 正文文字 | 白 α=0.87 或 token `#E8E3DA`：三档表面 7.87–13.79 全 AAA |
| 次要文字（画布/卡片档） | 白 α=0.58 起步可用；token `#9DB0A9` 在画布与卡片段落 ✅ |
| 强调色文字（画布场景） | `#00A862` = 5.69:1 AA ✅ |
| 白字 on 卡片 | 12.45 AAA |
| 金/浅金徽章 | `#cba258` 5.25 AA、`#dfc49d` 7.42 AAA（与亮色共用，天然一致） |
| 反白 CTA | 白底 + `#1E3932`(12.45) 或 `#006241`(7.44) 文字，层级成立且强于亮色版 |

### 🔧 需调整（附具体替换值）

| # | 问题 | 替换方案 |
|---|---|---|
| 1 | `accentOnSurface #D4E9E2` on 薄荷 = **2.44 ❌**（全场景失败） | 改深色文字：**`#101B17`** on `#00A862` = 5.69 ✅（复用画布 token，零新增色值）；禁用 `#006241` on 薄荷（2.40 ❌） |
| 2 | `textSecondary #9DB0A9` on `#274A40` = **4.31 ❌** | 提亮为 **`#A9BCB5`**（浮层 4.93 ✅ / 表面 6.25 ✅ / 画布 ≈8.4 AAA） |
| 3 | 薄荷绿作卡片小字 = 4.02 ❌ | 小字强调换 **`#00C77F`**（表面 5.62 ✅ / 画布 7.96 AAA）；`#00A862` 保留给图标/描边/大字 |
| 4 | 次要白 α 无红线约束 | 定稿写入：**α ≥ 0.62 为工程线，α < 0.55 一律禁止**（见第五节阶梯） |
| 5 | 薄荷实心按钮 + 白字 = 3.10 ❌ | 该组合禁止；实心薄荷按钮必须配墨绿/黑字，或维持"反白 CTA"主方案 |
| 6 | 弹窗内金色小字 4.14 ❌ | 浮层场景金色一律升级浅金 `#dfc49d`（5.85 ✅） |
| 7 | （待补项）危险红/错误态 on 三层表面 | 定稿前补测，建议同步给出 |

**一句话总结：深绿三层骨架成立、昼夜语义衔接良好；定稿前必须改两处——薄荷上的文字换成墨绿（2.44→5.69），浮层次要文字提亮到 `#A9BCB5`（4.31→4.93），再把「α≥0.62、<0.55 禁用」写进 token 规则即可整体达标 AA。**
