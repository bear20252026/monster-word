# 预计算词向量库方案

> **状态：已归档** — 本文档为早期概念探索，未进入实施阶段。方案思路已记录备查，实际实施需重新评估。
> 归档日期：2026-08-24

## 核心方案：字符 n-gram 向量 + Float16 存储

### 原理
- 对每个单词提取字符 2-gram/3-gram（如 "hello" → ["he","el","ll","lo","hel","ell","llo"]）
- 用哈希映射将每个 n-gram 映射到固定维度向量（如 64 维）
- 所有 n-gram 向量求和 → 单词向量
- 用余弦相似度计算词间相似度

### 优势
- **零依赖**：不需要任何 ML 模型，纯数学计算
- **离线运行**：全部本地计算，无网络需求
- **极小体积**：32,154 词 × 64 维 × 2字节(Float16) = 4MB
- **极速检索**：O(N) 余弦相似度，32K 词 < 10ms
- **OOV 支持**：任何单词都能生成向量（n-gram 覆盖）

### 实现步骤
1. Python 预计算脚本：读取 wordbook.db → 生成词向量 → 保存为 .bin 文件
2. Flutter 端：加载 .bin 文件 → 运行时余弦相似度检索
3. 集成到 DistractorEngine：编辑距离 + 词向量相似度混合评分

### 文件结构
```
assets/
  db/
    word_vectors.bin    ← 预计算词向量（~4MB）
```
