# 《外观设计专利请求书》填写指引

> 在专利业务办理系统（https://cponline.cnipa.gov.cn）在线填写。以下为逐字段填写内容，【】内为需要你补充的个人信息。

## 一、专利信息

| 字段 | 填写内容 |
|---|---|
| 申请类型 | 外观设计专利 |
| 产品名称 | 用于显示屏幕面板的签到图形用户界面 |
| 外观设计分类（洛迦诺） | 14-04（系统分类表中按提示选择"显示屏幕面板/图形用户界面"相关项） |
| 是否要求优先权 | 否 |
| 是否申请费用减缴 | 是（前提：先完成费减资格备案，见下文） |

## 二、设计人

| 字段 | 填写内容 |
|---|---|
| 设计人姓名 | 【真实姓名，与身份证一致】 |
| 设计人身份证号 | 【电子申请需填写】 |

> 注意：设计人应为对界面外观的实质性特点作出创造性贡献的人。如果是 AI 辅助完成，建议填你本人（AI 不是合法设计人主体），并保留创作过程记录（本项目的原型、迭代记录即为证据）。

## 五、费减资格备案（提交申请前完成，可省 425 元）

1. 条件（满足其一）：个人上年度月均收入低于 5000 元（年 6 万）；企业上年度企业应纳税所得额低于 100 万元；事业单位、社会团体、非营利性科研机构。
2. 办理：在专利业务办理系统内提交"费用减缴请求"，完成费减资格备案。
3. 结果：备案通过后，外观设计申请费 500 元 → 实缴 **75 元**（减缴 85%，单一申请人）。
4. 时效：**费减备案通过后再提交申请**才能享受减缴；先申请后备案不追溯。

## 六、随请求书提交的文件

1. 外观设计图片或照片：`images/` 目录 4 张（主视图 + 3 幅变化状态图），彩色 PNG，780×1688 像素。
2. 外观设计简要说明：见《01-外观设计简要说明.md》。
3. 实质审查请求：不需要（外观设计只有初步审查，无实审）。
