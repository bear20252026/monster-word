## 使用步骤

1. 补齐《02-请求书填写指引》中【】内的个人信息；先完成费减资格备案。
2. 登录 https://cponline.cnipa.gov.cn → 外观设计专利申请 → 新申请办理。
3. 产品名称填「用于显示屏幕面板的签到图形用户界面」；上传 images/ 4 张图（顺序：主视图 → 变化状态图 1/2/3）；粘贴《01》中简要说明。
4. 手机 APP 电子签名 → 提交 → 记下申请号 → 2 个月内缴费。

## 图片再生成方法（如界面迭代后需更新）

原型 `deliverables/calendar-checkin-prototype.html` 内置专利视图模式，用无头 Edge 截图：

```
msedge --headless=new --force-device-scale-factor=2 --window-size=560,900 \
  --screenshot=raw.png \
  "原型路径?patent=1&state=scatter|mid|grid|done"
```

再用 PIL 裁剪 (0,0,780,1688)。四种 state 对应四张视图。
