# 申请流程与费用说明（依据 2026-09-24 联网检索的现行规范）

## 一、法律依据

- 《专利法》（2020 修正）第 2 条第 4 款（外观设计定义）、第 23 条（授权条件）、第 27 条（申请文件）、第 40 条（初步审查授权）、第 42 条（保护期 15 年）
- 《专利审查指南》第一部分第三章：含图形用户界面的产品外观设计——动态 GUI 至少提交一个状态的整体视图，其余状态可仅提交关键帧视图，所提交视图应能唯一确定动态图案的变化趋势
- 《专利收费减缴办法》（财税〔2016〕78 号）：单一申请人减缴 85%

## 三、六步流程

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1. 注册 | cponline.cnipa.gov.cn 注册账号并实名认证 | 个人选自然人，企业选法人 |
| 2. 费减备案 | 系统内提交费减请求 | **先备案后申请**，备案通过后申请费 500→75 元 |
| 3. 撰写提交 | "专利申请及手续办理"→"外观设计专利申请"→"新申请办理" | 上传 4 张图片 + 粘贴简要说明；手机 APP 电子签名后提交 |
| 4. 缴费 | 受理后 1-2 个工作日收到受理通知书与缴费通知书 | 自申请日起 **2 个月内**缴纳，逾期视为撤回 |
| 5. 初审 | 初步审查（无实审）；可能收补正通知书 | 期限内答复补正，逾期视为撤回；初审合格约 **6 个月内授权** |
| 6. 办登领证 | 收到授权通知之日起 2 个月内缴登记费 | 外观设计登记费 210 元 + 当年年费；公告后发电子证书 |

## 四、费用清单

| 项目 | 标准 | 费减后（单一申请人） |
|---|---|---|
| 申请费 | 500 元 | **75 元** |
| 印花税 | 5 元 | 5 元 |
| 登记费+印花税（授权后） | 210 元 | 视当年政策 |
| 第 1-3 年年费 | 600 元/年 | 减缴后 90 元/年 |
| 代理费（如委托） | 800-2000 元/件 | — |

## 五、风险与注意事项（重要）

1. **新颖性窗口期**：申请前不要公开本界面。⚠️ 现状提示：monster-word 的 GitHub 仓库与应用发布已构成一定程度的公开，请**尽快提交**（专利法要求不属于现有设计；拖延会扩大在先公开范围）。如担心 GitHub 发布历史影响新颖性，可咨询代理人评估以"局部外观设计"（仅针对花齿徽章+聚合构图的局部区域）提交的替代方案。
2. **先例风险**：检索已确认腾讯、抖音、京东、平安均有"签到类 GUI"授权专利，cojeev-ui（MIT）已公开有机形状组件——本申请的保护点必须落在**整体构图与状态序列**（详见 design/聚宝日历签到页-外观专利设计说明.md 第八章），不要只主张花齿形状本身。
3. **火苗图标**：属行业惯常设计（多邻国等），视图保留无妨，但不要写入设计要点。
4. **图片规范**：已按要求制作——无背景干扰、无状态栏、无个人信息、色彩请求保护、关键帧能唯一确定变化顺序。若收补正（常见原因：视图比例不一致、简要说明与视图不一致），按通知书针对性修改即可。
5. **合案提示**：散落态/聚合态/签到完成态属同一产品的连续变化状态，已按一件申请的关键帧方式处理；如代理人建议拆分或合案其他界面，以代理人意见为准。

## 六、时间线预期

受理（1-2 个工作日）→ 缴费（2 个月内）→ 初审（约 3-6 个月，可能含 1-2 轮补正）→ 授权通知 → 缴登记费（2 个月内）→ 公告发证。**整体约 4-8 个月**。
